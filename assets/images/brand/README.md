# APMaths brand assets

Bộ logo vuông AP lưu trữ để tái sử dụng. Các biến thể giữ cùng hình học của biểu tượng AP, chỉ thay bảng màu.

- `ap-blue.svg` — xanh, bản thương hiệu chính.
- `ap-dark.svg` — nền tối.
- `ap-light.svg` — nền sáng.
- `ap-red.svg` — nền đỏ.

Slogan: **Analyze · Practice**.

Các file trong thư mục này là tài sản lưu trữ; website hiện tại vẫn dùng `/assets/images/ap-mark.svg` làm logo/favicon chính.
