Đọc dữ liệu UnT, đối chiếu đáp án và xuất kết quả theo chuẩn đầu ra học phần.

HƯỚNG DẪN NHANH

Chỉ cần 3 bước

Tải file đáp án mẫu
  1. Chọn file UnT. Cần có SBD, mã đề và các câu từ 1 đến đúng số câu của file đáp án. Nếu SBD trống/------, hệ thống sẽ đọc ảnh số phách ở cột B cùng hàng.
  2. Chọn file đáp án + CLO. Có thể dùng file mẫu để nhập đáp án đúng và CLO của từng câu.
  3. Nhấn Chấm bài. Khi dữ liệu hợp lệ, hệ thống cho phép xuất bảng điểm và bảng chi tiết CLO.
